# InterKarate
Игра International Karate для Atari 65XE.

Управление белым бойцом - стрелки, удар - пробел.

Управление красным бойцом - WASD, удар - Ctrl.

Можно подключить 2 джойстика через ардуину по такой схеме:
- А0 - Х первого джойстика
- А1 - У первого джойстика
- D2 - кнопка первого джойстика
- А2 - Х второго джойстика
- А3 - У второго джойстика
- D3 - кнопка второго джойстика
